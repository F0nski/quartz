L'idée

Sans REC, le clavier joue. REC le fait écrire, de trois façons :

  • GRID la grille (dans SEQ) : les 16 blanches sont les 16 pas de la page, comme sur une Elektron. On colle, on coupe, on tient un pas pour l'éditer.
  • NOTES 05 le mode NOTES : un curseur sur le pattern, déplacé par PRESET ; les 27 touches écrivent les notes du pas sous le curseur, puis il avance.
  • LIVE le live : ce qu'on joue s'enregistre là où ça tombe, pendant la lecture.

Par-dessus, des gestes repris de l'OP-Z : coller la dernière note jouée sur un pas vide, couper un pas pour le déplacer, l'entendre en le tenant, régler sa durée d'un geste, effacer en live. Et tout bouton tenu montre à l'écran ce qu'il permet.

Le clavier selon le mode

Cliquez sur un mode pour voir ce que fait chaque touche.

Jouer (désarmé)

Partout, SEQ compris, les touches jouent la piste choisie par ALGORITHM ; OCT− / OCT+ changent l'octave. Dans SEQ, le plateau reste affiché (il suit la page qui joue ; pour changer de page à l'arrêt, passer en GRID) et les LED des blanches montrent les pas allumés et le pas qui joue : on voit le pattern en cherchant une idée.

La dernière note ou le dernier accord joué (touches tenues ensemble) va dans le presse-papier, prêt à être collé sur un pas de la grille.

La grille GRID

Dans SEQ, un appui court sur REC. Les 16 blanches sont les pas de la page ; OCT− / OCT+ tournent la page (1–16, 17–32…). À l'arrêt comme en lecture. Un appui court est un appui relâché sans avoir rien réglé entre-temps.

Coller, couper, déplacer

  • Appui court sur un pas vide : il prend le presse-papier.
  • Appui court sur un pas allumé : couper. Son contenu part dans le presse-papier, le pas est vidé.
  • Déplacer : couper, puis appui court sur la case d'arrivée.
  • Dupliquer : couper, puis recoller sur sa case et sur chaque case voulue.

Le presse-papier

  • Un pas entier (notes, vélocité, durée, fonctions, p-locks), ou une note ou un accord joué.
  • Le dernier arrivé gagne : un pas coupé, ou une note jouée désarmé.
  • Commun aux 4 pistes. Au démarrage : C4. Une note collée sur un KIT devient le pad 1.

Plusieurs pas à la fois

SEL joue le rôle du SHIFT de l'OP-Z. SEL tenu, chaque appui sur un pas l'ajoute à la sélection ou l'en retire, sans l'allumer ni l'éteindre. Le premier pas choisi sert de référence (ses fonctions s'affichent). Toujours SEL tenu :

  • noires + PRESET : tous prennent la valeur de la référence, ajustée (tous à PROB 50 %, par exemple) ;
  • SLIDE, ACCENT : tous passent à l'inverse de la référence ;
  • K1–K4 : le même p-lock sur tous ;
  • OCT+ / OCT− : chacun gagne ou perd un pas de durée.

Relâcher SEL vide la sélection. SEQ tenu + blanches 1–8 choisit toujours le pattern.

Le mode NOTES NOTES 05

Dans SEQ, deux appuis courts sur REC (un seul ailleurs). Toutes les touches, noires comprises, sont des notes ; dans SEQ on voit le plateau, le viseur sur le curseur. Les LED allument les notes déjà écrites au pas sous le curseur.

  • Déplacer le curseur : PRESET, sur tout le pattern ; le plateau tourne la page tout seul. SEL + blanche n : directement au pas n de la page.
  • Une note ou un accord : jouer. Sur un pas vide, le pas est créé (vélocité 100, un demi-pas). Sur un pas allumé, seules les notes changent : vélocité, durée, fonctions et p-locks restent.
  • Le curseur avance de la durée du pas quand la dernière touche est relâchée. Pour corriger : PRESET d'un cran en arrière, rejouer.
  • Une note longue : touche tenue + PRESET (un pas par cran).
  • Sauter un pas (un silence) : PRESET d'un cran sans touche tenue, on avance sans écrire.
  • Régler le pas sous le curseur (dans SEQ) : K1–K4 directement, sur trois pages que SELECT fait défiler avant les pages de SEQ (STEPS, pour LEN, DIV, PATH). Tourner un encodeur sur un pas vide le crée.
  • Les p-locks du pas sous le curseur : SEL tenu + K1–K4, SEL tenu + SELECT pour la page de p-locks.

SLIDE et ACCENT : vers la droite actif, vers la gauche inactif. Hors de SEQ, K1–K4 restent ceux de la page affichée.

Dans SEQ, NOTES marche aussi en lecture (on corrige le pattern qui tourne), et l'arrêt ne le quitte pas. Hors de SEQ, à l'arrêt seulement : lancer la lecture y passe en live (avec le décompte s'il est activé). Tant que NOTES est actif, PRESET sert au curseur et ne change plus de pattern, de modèle ni d'insert.

Le live LIVE

Entrer

  • En lecture : REC tenu + PLAY ; la lecture continue. Hors de SEQ, REC armé en lecture suffit.
  • À l'arrêt, avec décompte (GLO, CLICK = COUNT ou BOTH) : REC tenu + PLAY, une mesure de décompte, puis l'enregistrement.
  • À l'arrêt, sans décompte : REC tenu + PLAY arme (ARM) ; la première note lance la lecture sur le premier pas.

Les notes s'enregistrent avec la quantisation de GLO, les encodeurs deviennent des p-locks, les punch-ins sont enregistrés. Dans SEQ, les touches restent des notes : on voit le plateau se remplir.

Effacer en jouant

  • REC tenu + touches : elles ne sonnent plus ; leurs notes sont retirées des pas que la lecture traverse.
  • REC tenu + OCT− tenu : chaque pas traversé est effacé.

REC (appui court) désarme, la lecture continue. PLAY arrête et désarme.

Les couches et leur aide

Un bouton qui pose une couche, tenu plus de 0,4 s, affiche sa carte à la place de la scène : le clavier avec le nom de chaque touche active, et les combinaisons avec les autres boutons. Les touches actives s'allument, la carte suit les appuis. Un appui court fait l'action du bouton ; un appui long ne la fait pas (REC ne bascule pas, SAVE ne sauvegarde pas).

Écran et LED

Badges de l'en-tête

  • GRID la grille
  • NOTES 05 le mode NOTES, curseur au pas 5
  • LIVE le live
  • ARM en attente de la première note

LED des blanches

  • dans SEQ (désarmé, GRID), mi-niveau : pas allumé
  • dans SEQ (désarmé, GRID), pleine : pas qui joue, pas sélectionné
  • NOTES : les notes du pas sous le curseur
  • bouton tenu : les touches actives de sa couche

La durée sur le plateau

Une note longue tire une bande verte au sol, du centre de son bloc vers les pas suivants, rangée après rangée (un chevron au changement de rangée, un trait clair à la fin). Pendant que la note sonne, la bande se remplit de rose. Une note qui sort de la page affiche +n >. Les pas sélectionnés sont orange, le pas tenu se soulève.

Limites

  • Pas de vélocité au clavier : les notes écrites ont la vélocité 100, à régler ensuite (noire 2).
  • La durée par OCT s'arrête à 8 pas.
  • Un CLEAR ne s'annule pas.
  • Les step components de l'OP-Z (PULSE, RAMP, STRUM, JUMP…) viendront avec leur propre spec ; leurs noires sont déjà réservées.
  • Pas de copier-coller de patterns entiers.
