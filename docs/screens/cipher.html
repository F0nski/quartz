CIPHER scènes, troisième série

À chaque pas, t = START × 256 + n × SPEED passe dans la formule, qui rend un octet de 0 à 255. Ses 8 bits décident du pas : les 3 bits hauts le rythme (contre DENS), le bit 4 l'accent, les 4 bits bas la note (ou le pad sur un KIT). Les trois écrans jouent la même boucle avec les mêmes knobs ; seule la mise en scène change.

bits 5–7 : le rythme bit 4 : l'accent bits 0–3 : la note ou le pad le pas qui joue

Troisième série

La formule, ses paramètres et t s'affichent en haut de B et C. Un pas qui joue est rose ; les couleurs des bits suivent la légende.
